# AI 기반 개인 메이크업 스타일 플래너

이 프로젝트는 사용자가 자신의 피부 톤과 원하는 상황을 입력하면, AI를 활용해 메이크업 색상 조합을 추천하거나 사용자가 직접 선택한 조합을 분석해 주는 웹 애플리케이션입니다.

## 1. 프로젝트 개요

사용자는 먼저 피부 톤을 설정한 뒤 두 가지 모드를 사용할 수 있습니다.

- 추천 모드: 상황과 원하는 분위기를 입력하면 AI가 메이크업 색상 조합을 추천해 줍니다.
- 조합 모드: 사용자가 립, 블러셔, 아이섀도우 색상을 직접 선택하면 AI가 설명해 줍니다.

얼굴 이미지 업로드는 사용하지 않으며, 화장품 상품 데이터 API도 사용하지 않습니다. 대신 직접 구성한 색상 팔레트와 점수 계산 로직, AI API를 활용합니다.

## 2. 주요 기능

### 2.1 피부 톤 설정

사용자가 자신의 퍼스널 컬러와 세부 톤을 선택합니다.

- 계절: 봄 웜톤, 여름 쿨톤, 가을 웜톤, 겨울 쿨톤
- 세부 톤: 라이트, 소프트, 트루, 클리어, 딥

이 설정은 추천 모드와 조합 모드의 기준으로 사용됩니다.

오른쪽 상단의 초기화 버튼을 누르면 피부 톤 설정이 기본값으로 돌아갑니다.

### 2.2 추천 모드

사용자가 상황이나 원하는 분위기를 입력하면 인공지능이 어울리는 색상 조합을 추천합니다.

추천 모드에서는 사용자의 계절 안에서 현재 세부 톤과 가까운 톤만 후보로 사용합니다. 예를 들어 라이트 톤이면 라이트와 소프트 톤만 후보로 사용합니다.

### 2.3 조합 모드

사용자가 립, 블러셔, 아이섀도우 색상을 직접 선택합니다.

조합 모드에서는 톤 단계 제한 없이 전체 팔레트에서 자유롭게 선택할 수 있습니다. 선택한 조합은 자체 점수 계산 로직으로 점수가 계산되고, 인공지능 설명을 요청할 수 있습니다.

선택 초기화 버튼을 누르면 립, 블러셔, 아이섀도우 선택값과 생성된 설명이 초기화됩니다.

### 2.4 얼굴 미리보기

선택한 립, 블러셔, 아이섀도우 색상이 얼굴 그림에 반영됩니다. 사용자는 선택한 색상이 얼굴에 어떻게 보이는지 시각적으로 확인할 수 있습니다.

### 2.5 점수 계산

색상 조합은 다음 기준으로 점수가 계산됩니다.

- 기본 점수
- 립 점수
- 블러셔 점수
- 아이섀도우 점수
- 조화 점수
- 최종 점수

조합 모드의 점수는 인공지능이 임의로 만드는 것이 아니라 프로젝트 내부 로직으로 계산됩니다.

## 3. 폴더 및 파일 설명

### 3.1 `src/`

프론트엔드 화면과 사용자 인터페이스를 담당하는 폴더입니다.

사용자가 보는 화면, 버튼, 색상 선택, 얼굴 미리보기, 점수 표시 등이 이 폴더 안의 코드로 구성됩니다.

### 3.2 `server/`

AI API와 연결되는 백엔드 서버 코드가 들어 있는 폴더입니다.

프론트엔드에서 사용자가 입력한 상황, 피부 톤, 색상 조합 정보를 서버로 보내면, 서버가 API 키를 사용해 인공지능 모델에 요청을 보내고 결과를 다시 화면에 전달합니다.

API 키는 보안상 프론트엔드 코드에 직접 넣지 않고 서버에서만 사용합니다.

### 3.3 `index.html`

웹 애플리케이션이 시작되는 기본 HTML 파일입니다.

React 앱이 이 파일을 기준으로 브라우저에 표시됩니다.

### 3.4 `package.json`

프로젝트 실행에 필요한 라이브러리와 실행 명령어가 적혀 있는 파일입니다.

주요 명령어는 다음과 같습니다.

```bash
npm.cmd run dev
npm.cmd run server
npm.cmd run build
```

### 3.5 `package-lock.json`

설치된 라이브러리의 정확한 버전을 기록하는 파일입니다.

다른 컴퓨터에서 `npm install`을 실행했을 때 같은 환경으로 설치되도록 도와줍니다.

### 3.6 `.env.example`

환경 변수 예시 파일입니다.

실제 API 키는 이 파일에 넣지 않고, 이 파일을 참고해 `.env` 파일을 따로 만들어 사용합니다.

```env
PORT=5174
VITE_API_BASE=

OPENAI_API_KEY=YOUR_API_KEY
OPENAI_BASE_URL=https://factchat-cloud.mindlogic.ai/v1/gateway
OPENAI_MODEL=gpt-5.1-chat-latest
```

### 3.7 `.gitignore`

제출하거나 공유하면 안 되는 파일을 제외하기 위한 설정 파일입니다.

예를 들어 실제 API 키가 들어 있는 `.env`, 설치된 라이브러리 폴더인 `node_modules`, 제작 결과물인 `dist` 등을 제외합니다.

## 4. `src/` 내부 구조

### 4.1 `src/App.jsx`

프로젝트의 핵심 화면 구성 파일입니다.

다음 기능들이 이 파일에서 연결됩니다.

- 첫 화면
- 피부 톤 설정 화면
- 추천 모드
- 조합 모드
- 얼굴 미리보기
- 현재 적용 색상 표시
- 점수 결과 표시
- 인공지능 추천 및 분석 요청

### 4.2 `src/main.jsx`

React 앱을 브라우저 화면에 연결하는 시작 파일입니다.

`App.jsx`를 불러와 실제 웹페이지에 렌더링합니다.

### 4.3 `src/styles/global.css`

전체 화면 디자인을 담당하는 CSS 파일입니다.

배경색, 버튼, 카드, 얼굴 미리보기 영역, 색상 선택 그리드, 반응형 화면 크기 조정 등이 이 파일에 정의되어 있습니다.

### 4.4 `src/data/`

앱에서 사용하는 고정 데이터를 모아 둔 폴더입니다.

#### `colorPalette.js`

립, 블러셔, 아이섀도우 색상 팔레트를 정의합니다.

각 색상은 계절, 톤, 색상 코드, 표시 이름 등을 가지고 있습니다.

#### `personalColors.js`

봄 웜톤, 여름 쿨톤, 가을 웜톤, 겨울 쿨톤과 라이트, 소프트, 트루, 클리어, 딥 같은 세부 톤 정보를 정의합니다.

추천 모드에서 허용되는 톤 범위도 이 파일에서 계산합니다.

#### `defaultSelection.js`

앱의 기본 선택값을 정의합니다.

처음 실행했을 때 기본 피부 톤과 메이크업 색상 선택 상태가 이 파일을 기준으로 정해집니다.

#### `scoringRules.js`

메이크업 조합 점수 계산에 필요한 규칙을 정의합니다.

피부 톤과 색상의 계절, 톤, 조화 여부 등을 기준으로 점수를 계산할 수 있게 합니다.

#### `uiLabels.js`

화면에 표시되는 부위 이름을 정의합니다.

예를 들어 립, 블러셔, 아이섀도우 같은 라벨이 이 파일에 있습니다.

### 4.5 `src/utils/`

계산과 분석에 필요한 보조 기능을 모아 둔 폴더입니다.

#### `calculateScore.js`

사용자가 선택한 립, 블러셔, 아이섀도우 조합의 점수를 계산합니다.

기본 점수, 부위별 점수, 조화 점수, 최종 점수를 산출합니다.

#### `generateAnalysis.js`

API 연결이 없거나 사용자가 아직 인공지능 설명을 요청하지 않았을 때 보여줄 기본 분석 문장을 생성합니다.

#### `getSkinColor.js`

선택한 피부 톤에 맞는 얼굴 미리보기용 피부색을 가져옵니다.

## 5. `server/` 내부 구조

### 5.1 `server/index.js`

백엔드 서버의 시작 파일입니다.

프론트엔드에서 오는 요청을 받아 다음 API 경로로 처리합니다.

- `/api/health`
- `/api/recommend`
- `/api/analyze-combination`

### 5.2 `server/aiClient.js`

AI API 호출을 담당하는 파일입니다.

추천 모드에서는 상황과 피부 톤을 바탕으로 색상 조합을 추천하고, 조합 모드에서는 사용자가 직접 선택한 조합에 대한 설명을 생성합니다.

API 키가 없을 경우에는 예시 응답을 반환해 앱이 기본적으로 동작할 수 있도록 합니다.

## 6. 실행 방법

### 6.1 라이브러리 설치

```bash
npm install
```

### 6.2 환경 변수 설정

`.env.example`을 참고해 `.env` 파일을 만들고 API 키를 입력합니다.

```env
OPENAI_API_KEY=본인의_API_KEY
```

### 6.3 서버 실행

```bash
npm.cmd run server
```

### 6.4 프론트엔드 실행

새 터미널을 열고 다음 명령어를 실행합니다.

```bash
npm.cmd run dev
```
